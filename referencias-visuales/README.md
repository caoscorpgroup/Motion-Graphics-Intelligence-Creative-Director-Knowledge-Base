# Referencias visuales

Esta carpeta conserva un conjunto reducido de referencias visuales para el Director Creativo. Las imágenes no son una colección de estilos que deban copiarse ni sustituyen las directrices escritas.

## Estructura

- `aprobadas/`: referencia editorial 2.5D elegida expresamente por el usuario como guía visual principal.
- `por-clasificar/`: imágenes originales pendientes de determinar su función concreta.
- `animacion-seleccionada/`: diez GIF elegidos como muestras complementarias de movimiento, personajes 2D, poses, composición, color y recursos gráficos.

## Cómo deben utilizarse

1. La referencia de `aprobadas/` define el nivel de ilustración y el lenguaje visual principal.
2. Los GIF de `animacion-seleccionada/` pueden estudiarse para principios de movimiento, ritmo, poses, secuencias, transiciones y composición temporal. No deben convertirse automáticamente en la estética de todos los proyectos.
3. Las imágenes de `por-clasificar/` no se consideran directrices hasta que se identifique su utilidad.
4. Las referencias sirven para estudiar principios y ampliar el repertorio; no para copiar obras ni reproducir exactamente el estilo de un artista.
5. Conservar autor, fuente y enlace cuando se conozcan. No modificar ni sobrescribir originales.
