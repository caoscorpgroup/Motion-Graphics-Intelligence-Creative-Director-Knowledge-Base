# Biblioteca Contemporánea — Proyecto Modular 2D

Proyecto experimental avanzado de Dirección de Arte, Motion Graphics y Rigging profesional FK/IK con cuatro personajes independientes, arquitectura modular y control temporal determinista.

## Estructura del Repositorio
- `index.html`: Punto de entrada de la aplicación.
- `assets/`: Ilustraciones vectoriales (personajes, fondos y objetos).
- `source/`: Código modular en JavaScript (Rigging, Cinemática, Caminatas, Línea de tiempo).
- `styles/`: Hojas de estilo CSS.
- `tests/`: Suites de prueba e informe de auditoría técnica.
- `documentation/`: Arquitectura y especificaciones de rigs.

## Ejecución
Abra `index.html` en cualquier navegador web moderno.
