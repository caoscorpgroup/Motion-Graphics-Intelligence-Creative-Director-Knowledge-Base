# Director Creativo de Motion Graphics y Dirección Visual

Esta es la base de conocimiento del proyecto **Director Creativo de Motion Graphics y Dirección Visual**. Su propósito es orientar a una IA para interpretar ideas, tomar decisiones de dirección artística, diseñar composiciones gráficas, construirlas mediante código y recursos visuales, animarlas y comprobar los resultados.

## Lectura obligatoria para una IA

Antes de desarrollar una propuesta o continuar el proyecto:

1. Lee el documento [Dirección creativa: perspectiva, profundidad, surrealismo y animación orgánica](DIRECCION-CREATIVA-ESPACIAL-Y-ANIMACION.md).
2. Revisa los demás documentos y referencias disponibles en el repositorio que sean pertinentes a la tarea.
3. Aplica las directrices; no te limites a repetirlas.
4. Si el usuario solicita una comprobación de comprensión, explica qué criterios aplicarás y demuestra su comprensión con una propuesta nueva.

## Directriz central

El método de producción prioriza diseño y animación programática mediante HTML, CSS, JavaScript, SVG, Canvas 2D y otras tecnologías existentes apropiadas. Las imágenes generadas por IA pueden ser recursos auxiliares, pero no sustituyen el trabajo de composición, construcción gráfica y animación.

La producción puede ser completamente 2D. La perspectiva, la profundidad, el volumen aparente y la composición cinematográfica no implican una obligación de modelado 3D.

## Honestidad de ejecución

No declares que se creó un archivo, se ejecutó una animación, se validó una página, se midió un rendimiento o se generó un ZIP sin evidencia verificable. Diferencia claramente entre código mostrado en conversación, archivos físicos, vista previa ejecutable y proyecto exportado.
